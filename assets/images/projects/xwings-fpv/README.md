## Image Guidelines

- **Format**: JPG or PNG
- **Resolution**: Minimum 1920x1080 for gallery images, 800x800 for team photos
- **Aspect Ratio**: 16:9 for gallery images, 1:1 (square) for team photos
- **File Size**: Keep under 2MB per image for web optimization
- **Naming**: Use lowercase with hyphens (e.g., `team-photo-2024.jpg`)
